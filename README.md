# Lumina Reader

A sequential image and manga reading ecosystem rewritten in modern React, TypeScript, Tailwind CSS, and Express with Gemini API integration.

## Key Features

- **Lumina Noir AMOLED Experience**: Designed for OLED/AMOLED deep blacks (`#000000`) with violet (`#8B5CF6`) and cyan (`#00E5FF`) accents.
- **High-Performance Reader Engine**:
  - Continuous Webtoon vertical scroll tiling
  - Single-page Comic LTR & Manga RTL modes
  - Dual-page spread mode
  - Scrubber progress control and zoom / brightness calibration
- **Lumina Flow Dynamic Ambient Immersion**: Real-time ambient RGB edge and background backlighting synchronized to active manga panels.
- **Lumina Snap 1-Second State Restore**: Instant session bookmarks, reading progress tracking, and multi-series snapshot switcher modal.
- **Manga Universe Map**: Interactive 2D lore constellation graph featuring character nodes, faction markers, power tiers, and relationship edges.
- **Manga DNA & Intelligence**: Reading velocity (PPM), streak tracking, genome resonance trait bars, and achievement XP progression.
- **Lumina Forge Studio**: Custom reading experience packs with tuned haptics, theme palettes, and audio profiles.
- **Lumina Mutation Engine**: Adaptive autonomous reading behavior algorithms (Day 30 Evolution model).
- **Lumina AI Assistant**: Server-side Gemini integration providing semantic chapter breakdowns, lore analysis, and tailored recommendations.
- **Sources & Extensions Management**: Keiyoushi index synchronization, multi-language package filtering, and ProtoBuf endpoint management.
- **Backup & Cloud Sync**: Local `.lumina` backup archive generation and cloud synchronization.
